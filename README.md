# VishTech AI Translator

An enterprise-grade, highly optimized Language Translator dashboard built using Python, Streamlit, and high-performance AI translation models. 

Developed by **Aman Singh** for the **CodeAlpha Artificial Intelligence Internship 2026**.

## 🚀 Key Features

* **Instant Translation:** Powered by robust machine learning pipelines.
* **Auto-Detect Language:** Smart detection system for origin parsing.
* **Voice Integration:** Direct Speech-To-Text processing frameworks and text-to-speech outputs.
* **Professional Exporting:** Native Indian font-supported `.PDF` structures and `.TXT` distribution formats.
* **Modern Interface:** Includes Light/Dark theme switching, tooltips, and real-time ledger histories.
